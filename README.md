Entry for the make.fun bounty **The Funniest Sick-Day Excuse**: a tiny
deterministic Node 22 program (`main.ts`, stdlib only, no network, no
wall-clock, no randomness) that writes one original one-line sick-day excuse
to `/output/entry.txt`, with a 1–200 character gate validation and a read-back
self-check.

The excuse: a sore throat so bad the sender sounds like a dial-up modem —
half believable, fresh, and the funniest word lands on the very last words.

Run it:

```sh
node main.ts [output-dir]
```

With no argument it writes to `/output/entry.txt`.
